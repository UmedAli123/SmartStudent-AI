# SmartStudent AI: Performance Tracking & Prediction System

**Developed by: Manaal Sheikh**

SmartStudent AI is a cutting-edge, full-stack web application designed to empower educators with data-driven insights. By leveraging advanced Machine Learning, the system predicts student academic outcomes and identifies potential risks in real-time.

## ✨ Features

- **🧠 ML Prediction Engine**: Analyzes academic scores, attendance, and study habits to predict final grades and risk levels.
- **📊 Interactive Dashboard**: A premium, glassmorphic interface providing a high-level overview of student performance metrics.
- **📁 Student Directory**: Seamless management of student profiles and academic records.
- **📜 Analysis History**: Persistent log of all AI-generated evaluations for long-term progress tracking.
- **🚀 Deployment Ready**: Pre-configured for seamless hosting on platforms like Render or Railway with PostgreSQL support.

## 🛠️ Tech Stack

- **Backend**: Python, Flask, SQLAlchemy (ORM)
- **Frontend**: Vanilla HTML5, CSS3 (Custom Glassmorphism), JavaScript
- **Icons**: Lucide Icons
- **Database**: SQLite (Local), PostgreSQL (Production)
- **Machine Learning**: Scikit-learn, Pandas, Numpy

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- pip

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/UmedAli123/SmartStudent-AI.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Access the dashboard at `http://localhost:5001`.

## 🌐 Deployment

This project is optimized for **Render**. To deploy:
1. Push your code to GitHub.
2. Create a new **Web Service** on Render.
3. Connect your repository.
4. Add the `DATABASE_URL` and `SECRET_KEY` environment variables.
